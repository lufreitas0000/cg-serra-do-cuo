# Serra do Cuó Climbing Guidebook

This is the guidebook workspace for Serra do Cuó. It consumes the `cg-engine` logic as a submodule.

## Setup
```bash
git clone --recurse-submodules https://github.com/lufreitas0000/cg-serra-do-cuo.git
cd cg-serra-do-cuo
dvc pull
```

## Compilation
```bash
make build
make validate
```
